# Замена иллюстрации первого экрана

## Цель

Заменить текущую иллюстрацию девушки в первом экране на предоставленный пользователем файл `hero-image.webp`.

## Решение

- Скопировать исходный файл в `site-copy/images/hero-image.webp`.
- Заменить только ссылку на изображение целевого элемента первого экрана.
- Сохранить контейнер и его адаптивное поведение; для изображения использовать `object-fit: contain`, чтобы оно не растягивалось и не обрезалось.

## Проверка

- Локальная страница открывается без внешней зависимости от файла пользователя.
- Изображение отображается в первом экране целиком и без искажений.
