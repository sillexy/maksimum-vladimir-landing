# Максимум Владимир — лендинг

Сайт публикуется автоматически через GitHub Pages из папки `site-copy`.

## Как изменить сайт через GitHub

1. Откройте папку [`site-copy`](site-copy).
2. Нажмите на нужный файл, затем на значок карандаша **Edit**.
3. Сохраните изменения кнопкой **Commit changes** в ветку `main`.
4. GitHub Pages обновит сайт автоматически в течение нескольких минут.

Главная страница — [`site-copy/index.html`](site-copy/index.html).
